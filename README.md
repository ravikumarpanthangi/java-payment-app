# Java Payment App — AI Agent CI/CD Pipeline

This project demonstrates an AI Agent powered CI/CD pipeline
built using LangGraph and Groq LLM.

## What the AI Agent does automatically:
- Reads and analyses code changes from GitHub
- Runs Maven build and fixes errors automatically
- Analyses test failures and suggests fixes
- Makes deployment decisions intelligently
- Monitors application health post-deployment

## Tech stack:
- Java — application code
- LangGraph — AI agent orchestration
- Groq LLM — AI brain Llama 3.3
- AWS — deployment target
- Python — agent code

## Result:
3 engineers x 15 days OLD way
1 person x 25 minutes NEW way with AI Agent
